# Kartenwerk

Ein kostenloses Browser-Tool zum Drucken deutscher
Magic: The Gathering-Proxies aus Decklisten.

➡️ [Kartenwerk öffnen](https://kartenwerk.manuel-rumpfhuber.workers.dev/)

## Funktionen

- Englische und deutsche Kartennamen eingeben
- Verfügbare deutsche Kartenbilder auswählen
- Englische Ersatzkarten optional erlauben
- Token und Planeswalker-Embleme separat hinzufügen
- Bestimmte Druckversionen über Set-Code und Sammlernummer auswählen
- Druckbögen für A4 und US Letter erstellen
- Über den Browser drucken oder als PDF speichern

## Beispiele für die Deckliste

Eine Karte pro Zeile. Set-Code und Sammlernummer
helfen, bestimmte Druckversionen und Token auszuwählen:

    1 Lightning Bolt (STA) 42
    1 Forest (NEO) 291
    2 Robot (TPIP) 16
    1 Wrenn and Six Emblem

Für englischsprachige Token und Embleme
„Englisch als Ersatz erlauben“ aktivieren.
